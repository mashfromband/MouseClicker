# MouseClicker

自分用の macOS 連打クリックアプリ (SwiftUI)。クリック回数・間隔・ボタン・開始待ち時間を指定できます。

## ビルドと起動
```
./scripts/build_app.sh
open build/MouseClicker.app
```
(macOS 13+ / Xcode Command Line Tools が必要)

## 使い方
- 初回は「システム設定 › プライバシーとセキュリティ › アクセシビリティ」で MouseClicker を許可
- 回数・間隔(ms)を設定し「開始」。待ち時間の間にマウスをクリックしたい場所へ移動
- 固定位置: 「3秒後に位置を記録」でその座標を毎回クリック (未設定ならカーソル位置)
- **F6** で開始/停止、**Esc** で停止 (他アプリ操作中も有効)
- **マウスボタントリガー** (既定: 中ボタン): ゲーム中でもそのボタンを1回押すと連打開始、もう1回押すと停止 (開始待ちなし)。設定でサイドボタンにも変更可

## アクセシビリティ許可が効かないとき
再ビルドするとアプリの署名が変わり、古い許可が無効になります。
1. システム設定 › アクセシビリティ で MouseClicker を `−` で削除
2. `tccutil reset Accessibility local.mouseclicker`
3. アプリを起動し直して再度許可 (ビルドスクリプトは固定の自己署名証明書で署名するため、以降の再ビルドでは維持されます)
`swift run` やターミナルから直接実行した場合は、許可の対象がターミナルになります。必ず `build/MouseClicker.app` を起動してください。
